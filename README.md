Sunline Trophy Desk is an offline guide and tracker for the 55 official PS5 trophies. The page is a sunlit desk: warm paper, dark ink, and a short brass accent. It keeps a checklist with saved progress, a six-stage path to the platinum, a missable timing table, and the public pages those notes came from. Everything the browser needs lives under app/ and works with the network off.

## Run it

```
node serve.ts
```

Open the local URL it prints. The site root is app/.
